# ♻️ Waste Segregation using Deep Learning

An AI-powered web application that classifies waste images into different categories (plastic, paper, cardboard, glass, etc.) using a deep learning model built with EfficientNet. The project helps in automating waste classification for better recycling and environmental sustainability.

---

## 🚀 Live Demo

---

## 📌 Project Features
- Upload or capture waste images
- Real-time prediction using trained CNN model
- Classifies waste into multiple categories
- Simple and interactive Streamlit web interface
- Supports image preprocessing and augmentation

## 🧠 Tech Stack
- Python 🐍  
- TensorFlow / Keras  
- EfficientNet (Transfer Learning)  
- Streamlit (Frontend)  
- OpenCV / PIL
